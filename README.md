# Smart Farming Assistant 🌱

## Project Overview
Smart Farming Assistant is an IoT-based project designed to help farmers monitor important agricultural conditions using sensors and ESP32-CAM.

## Objectives
- Monitor soil moisture.
- Measure temperature and humidity.
- Monitor soil pH.
- Detect rainfall.
- Provide useful alerts to farmers.

## Components
- ESP32-CAM
- Soil Moisture Sensor
- Temperature and Humidity Sensor
- Soil pH Sensor
- Rain Sensor

## Working
Sensors collect agricultural data. The ESP32 processes the information and helps farmers understand field conditions.
