# Smart Farming Assistant

## Project Description
An IoT-based smart farming system designed to help farmers monitor field conditions using ESP32 boards and sensors.

## Hardware Components
- ESP32 DevKit
- ESP32-CAM
- Soil Moisture Sensor
- DHT11/DHT22
- Soil pH Sensor
- Rain Sensor

## Technologies
- Arduino IDE
- Embedded C/C++
- Internet of Things (IoT)

## Features
- Soil moisture monitoring
- Temperature and humidity monitoring
- Soil pH monitoring
- Rain detection
- Camera image capture

## Future Scope
- Mobile application integration
- Cloud-based data monitoring
- Automated irrigation alerts
